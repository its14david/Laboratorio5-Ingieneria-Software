01 · Entorno de desarrollo del software

Comprender dónde y por qué se desarrolla el software

En este laboratorio, el entorno se entiende como el contexto organizacional y operativo que debe conocerse antes de definir la solución tecnológica.

Introducción

El desarrollo de software parte de una necesidad real de una organización. Por eso, primero se estudia cómo funciona el negocio y qué resultados espera obtener.

  • Objetivos y necesidades
  • Procesos y flujo de trabajo
  • Roles y responsabilidades
  • Problemas y oportunidades

Entendimiento del negocio

Consiste en conocer las actividades, decisiones, información, participantes y reglas que permiten que la organización opere.

  • Clientes, empleados y proveedores
  • Documentos y datos utilizados
  • Reglas del negocio
  • Resultados esperados

Mejoramiento del proceso actual

Analizar el proceso actual también permite detectar tareas innecesarias, duplicaciones, demoras o errores y plantear un proceso más eficiente.

  • Eliminar actividades sin valor
  • Reducir duplicidad
  • Mejorar tiempos de respuesta
  • Definir controles

Técnicas de recopilación de datos

La comprensión del negocio puede apoyarse en técnicas de recopilación antes de elaborar los modelos.

  • Entrevistas
  • Observación directa
  • Revisión de documentos y registros
  • Talleres con interesados

Proceso actual

Puede presentar tareas manuales, esperas, duplicación de información, errores o falta de visibilidad.

Proceso mejorado

Busca simplificar actividades, mejorar el flujo de información y preparar una base clara para el sistema.

02 · El modelo del negocio

Representar cómo funciona la organización

El modelado ayuda a visualizar el negocio y comunicar sus procesos con menos ambigüedad antes de diseñar la solución informática.

Modelo del Dominio

Representa conceptos importantes del negocio y sus relaciones, creando un vocabulario común para quienes participan en el proyecto.

Modelo de Casos de Uso del Negocio

Describe procesos del negocio desde la perspectiva de los actores y de los objetivos que buscan alcanzar.

Modelo de Objetos del Negocio

Identifica los principales objetos o elementos de información que participan en las actividades y reglas del negocio.

Modelo de Objetos del Negocio

¿Qué elementos participan en esos procesos?

El modelo ayuda a identificar elementos de información y conceptos utilizados por la organización y las relaciones que se manejan en el negocio.

Cliente

Persona que realiza o solicita una compra.

Producto

Artículo comercial con código, precio y existencia.

Venta

Transacción que registra productos, cantidades y total.

Detalle de venta

Relaciona cada producto con una venta.

Inventario

Controla las existencias disponibles.

Proveedor

Suministra productos al supermercado.

Cajero

Procesa las ventas de los clientes.

Pedido

Solicitud para abastecer inventario.

Reporte

Resume información para la gestión.

Pasando del Modelo del Negocio al Modelo del Sistema

Convertir conocimiento en una solución tecnológica

La transición transforma procesos, necesidades y conceptos validados en requisitos y estructuras que pueden ser implementados.

Modelo del negocio

Describe objetivos, procesos, actores, reglas, conceptos y relaciones de la organización.

Modelo del sistema

Describe cómo una solución informática puede soportar las necesidades identificadas.

Negocio: “Registrar venta”
Sistema: “Procesar venta”
Negocio: “Producto”
Sistema: clase / entidad Producto
Negocio: “Administrador”
Sistema: rol con permisos
Negocio: “Actualizar inventario”
Sistema: servicio de inventario
Negocio: regla de descuento
Sistema: regla validada
Negocio: “Reporte de ventas”
Sistema: módulo de reportes
Idea clave: el modelo del sistema debe surgir de lo que se comprendió, documentó y validó del negocio; no debe inventar necesidades desconectadas del proceso real.
